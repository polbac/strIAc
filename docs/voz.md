# Voz y copy

## Tono

- Preciso, curatorial, un poco clínico-biológico sin ser frío
- Puede volverse poético si el release lo pide
- Registro cercano a arte contemporáneo / sound art
- No suena a press de EDM ni a marketing de startup

**Verbos útiles:** mutar, recorrer, negociar, generar, intervenir, trasponer, habitar, filtrar.

**Evitar:** banger, drop, vibes, “cutting-edge AI art”, “immersive experience” vacío, “pushing boundaries”.

## Ejemplos (del catálogo)

**Bueno:**
> INFRAMUNDO es un conjunto de 8 tracks + una aventura gráfica que recorre distintos paisajes sonoros y en movimiento permanente, generados a partir de código en un navegador web.

**Bueno:**
> Primer compilado de Strlac Records. Este no solo puede ser escuchado sino que también puede ser recorrido en su versión online.

**Evitar:**
> Exciting new experimental release from an innovative Buenos Aires label pushing boundaries in electronic music.

## Estructura de copy Bandcamp / press

```markdown
[TÍTULO]

[1–3 párrafos: qué es el proyecto, cómo se hizo, qué capas tiene]

[Detalle de edición física / bonus / link a versión online]

credits
[créditos]

[fecha]
```

### Reglas

1. La primera frase define el objeto (qué es), no hace teaser vacío.
2. Mencionar capas no-audio si existen.
3. Incluir links a web o código cuando sean parte del release.
4. Créditos y grafías de artistas tal como en el proyecto (`Latigx`, `POLBAC`, `NIXON`).
5. Cerrar con la identidad del sello solo si el canal no la muestra ya.
6. Si hace falta inglés: bloque paralelo completo, no frases mixtas.

## Capsules para redes

Una pieza = **una idea + un visual + un link**.

Evitar walls de texto bilingüe. Preferir ES; EN solo si el canal o el release lo requieren.
