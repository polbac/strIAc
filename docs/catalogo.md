## Modelo de release

Todo proyecto sigue el flujo de [workflows.md](workflows.md):

1. **Input** — contacto (strlac → artista o artista → strlac)
2. **Construcción conjunta** — el proyecto se arma entre sello y artista
3. **Output** — release digital + web expandida + físico; evento opcional

## Patrones curatoriales

1. **Tríada de salidas** — digital / web expandida / físico (evento si suma)
2. **Live / sistema** — negociación humano–máquina, software propio, grabaciones en espacios de arte sonoro
3. **Territorio** — investigaciones locales mutadas por medios digitales (p. ej. chamamé / litoral)
4. **Edición limitada táctil** — polaroids u objetos únicos
5. **Créditos colectivos** — agradecimientos a artistas; a veces firma corta (“Faktor, Pol, Nix. Strlac.”)

Estos patrones sirven para curaduría, copy y para decidir qué assets pedir en el intake.
