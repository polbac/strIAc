## Instrucciones rápidas

1. Antes de copy, gráficos o automatización → leer el doc correspondiente en `docs/`.
2. Proceso de release: **contacto → construcción conjunta → digital + web expandida + físico** (evento opcional). Ver `docs/workflows.md`.
3. No inventar roster, fechas, IDs, precios ni tokens visuales vacíos.
4. Al cerrar un release → actualizar `docs/catalogo.md`.

## Qué no hacer

- Tratar strlac como techno club label o vibe futurista genérico
- Rellenar `brand/tokens.yaml` con defaults AI
- Sobreescribir la identidad visual de un artista sin pedirlo
- Hardcodear voz/visual en scripts: siempre leer `docs/`
